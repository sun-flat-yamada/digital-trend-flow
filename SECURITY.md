# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do NOT open a public GitHub Issue for security vulnerabilities.**

### How to Report

1. **GitHub Private Security Advisory** (Preferred):
   Navigate to the [Security tab](../../security/advisories) of this repository and click "Report a vulnerability."

2. **Email**: Contact the repository owner directly.

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial assessment**: Within 1 week
- **Fix or mitigation**: Best effort, depending on severity

### Scope

This policy covers:
- Source code in this repository
- GitHub Actions workflows
- Dependencies used by this project

### Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest  | ✅        |

Thank you for helping keep this project secure.
